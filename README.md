# SMART TERMINAL HR — วิธีติดตั้ง

ระบบนี้เป็นเว็บแอปไฟล์เดียว (`index.html`) ที่ต่อกับฐานข้อมูล Supabase โปรเจกต์ **SMART HR** (`cnqafxdrnlggswqzbxgr`) ซึ่งสร้างและตั้งค่าไว้เรียบร้อยแล้ว **ไม่ต้องรัน SQL เพิ่ม**

## ขั้นตอน
1. สร้าง GitHub repository แบบ private แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
   (index.html, manifest.json, icon-192.png, icon-512.png, logo.png และโฟลเดอร์ fonts — แบบอักษร Kanit ฝังในแอป ไม่ต้องโหลดจากภายนอก)
2. ที่ Vercel → Add New Project → เลือก repository นั้น → Deploy (ไม่ต้องตั้งค่า build)
3. เปิดโดเมนจาก Vercel → เข้าสู่ระบบด้วยบัญชีผู้สร้างระบบ แล้วเปลี่ยนรหัสผ่านทันที
4. ตั้งค่าระบบ → บริษัทและโลโก้ → อัปโหลด `logo.png` (เก็บใน File Storage)
5. ข้อมูลพนักงาน → นำเข้า Excel → เลือกไฟล์ `SMART_Employees_Active_HR_App.xlsx` → ตรวจตัวอย่าง → ยืนยัน
6. ตั้งค่าระบบ → รายการรอยืนยัน → กรอกข้อมูล OI-01 ถึง OI-15 ตามลำดับ
   (สำคัญที่สุด: สายอนุมัติขั้นที่ 3 / กะการทำงาน / นโยบายการลา / ค่าเงินเดือน)
7. ตั้งค่าระบบ → ผู้ใช้และสิทธิ์ → เลือกพนักงาน → สร้างบัญชี (ระบบสุ่มรหัสผ่านและให้ดาวน์โหลดครั้งเดียว)

## หมายเหตุ
- เปิดไฟล์ในตัวอย่างของแชทจะเชื่อมฐานข้อมูลไม่ได้ ต้องเปิดผ่านโดเมน Vercel (หรือเว็บเซิร์ฟเวอร์ใดก็ได้)
- หน้าเว็บมีเฉพาะ publishable key — ห้ามใส่ service_role key ลงในไฟล์
- ชื่อผู้ใช้ = รหัสพนักงาน (ระบบแปลงเป็นอีเมลภายใน `<รหัส>@hr.smartterminal.app`)
